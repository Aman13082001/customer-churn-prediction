# customer-churn-prediction

End-to-end Machine Learning project for customer churn prediction using Logistic Regression, Decision Tree, Random Forest, and XGBoost with EDA, feature engineering, model evaluation, and business insights.
## Project Overview

Predict customer churn using machine learning models.

## Dataset
- Telco Customer Churn Dataset
- 7043 customers
- 19 features

## Models Used
- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost

## Results

| Model | Accuracy |
|---------|---------|
| Logistic Regression | 80.48% |
| Decision Tree | 72.67% |
| Random Forest | 79.49% |
| XGBoost | 78.78% |

Best ROC-AUC Score: 0.848

## Business Insights

- Contract type strongly affects churn.
- Monthly charges impact churn risk.
- Long-tenure customers churn less frequently.
